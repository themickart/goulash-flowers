# Goulash.tech Flowers — концепт-лендинг

Тестовое задание: лендинг системы автоматизации для цветочных магазинов с доставкой.

## Что внутри

**Секции:**
- Hero с LED-бордом (пиксельная анимация цветочных спрайтов)
- «Как работает» с видео-плеером и главами
- «Где теряет деньги» — боли аудитории
- **Кабинет Гуляша** — 3 интерактивных виджета:
  - Мастерская: живая канбан-очередь сборки с фильтрами по каналам
  - Маршруты курьеров: canvas-карта с переключением «Вручную / Гуляш» и «Обычный / 8 марта»
  - Склад свежести: симуляция остатков с ползунком по дням
- **CRM / Поводы** — список клиентов с фильтрами, сегментами и отправкой push-уведомлений
- **Пиковые дни** — таймер обратного отсчёта до 8 марта / 14 февраля / 1 сентября + план подготовки
- **Форма заявки** — валидация, состояния загрузки / успех / ошибка
- FAQ accordion

## Запуск

```bash
npm install
npm run dev     # dev-сервер на localhost:5173
npm run build   # production build → dist/
npm run deploy  # gh-pages деплой
```

## Стек

- Vite 6 (без фреймворков)
- Vanilla JS (ES modules)
- Lenis (smooth scroll)
- CSS Custom Properties (дизайн-токены)
- Pixeloid Sans (пиксельный шрифт для LED-борда)
